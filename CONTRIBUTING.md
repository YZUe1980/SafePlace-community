# Contributing to SafePlace

Thank you for your interest. This is a **public planning and feedback repository**; no runnable Android source code is published here.

## Useful contributions

- Propose a feature or accessibility improvement, with a clear real-world use case.
- Link to an official public safety data source, its documentation, geographic coverage, update frequency and licensing.
- Identify confusing wording in safety explanations or risk-score designs.
- Suggest translations of non-critical UI text, with language and regional context.
- Report broken public documentation links or unclear release-status statements.

## Please do not

- Post personal location histories, medical records, phone numbers, credentials, API tokens or other private information.
- Publish security vulnerabilities here; see [SECURITY.md](SECURITY.md).
- Submit fabricated risk scores, unverified emergency phone numbers or invented warning notices as facts.
- Claim an official endorsement, functioning app, or guaranteed risk prediction.
- Open pull requests containing executable app code without prior discussion and explicit project approval.

## Contribution process

1. Search existing issues first.
2. Open a concise GitHub issue explaining the need, supporting source(s), expected behavior and possible risks.
3. For changes to public documentation, discuss larger changes before opening a pull request.
4. Clearly label proposals and assumptions; maintainers decide whether and when to adopt them.

## Rights

By submitting a contribution you warrant you have the right to submit it. **No blanket open-source code license has been selected.** For substantive documentation or media contributions, we must agree on reuse permission before incorporation.

We value respectful discussion and evidence-backed critique. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
