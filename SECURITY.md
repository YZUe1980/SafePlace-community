# Security policy

**Status:** SafePlace is in concept and research phase; no public application build is released.

## Sensitive security reports

Do **not** open public issues containing:
- exploitable vulnerabilities, credentials or access tokens;
- private user data or exact locations;
- detailed instructions to compromise emergency information or critical safety functions.

Use GitHub's private vulnerability reporting feature **if it is enabled for this repository**. If it is unavailable, do not publish exploit details; a verified private reporting channel will be announced before a public app release.

No public repository file or issue authorizes access to live infrastructure or security testing against third-party services.

## Safety-critical misinformation

If a public project statement suggests an unverified hazard, erroneous emergency number or incorrect authority attribution, flag the issue without repeating sensitive personal information. The project is **not** a real-time emergency alert service.

## Supported versions

There are no released or supported software versions yet.
